# Generaluz CRM

Generaluz CRM es una aplicación web para la gestión de clientes, presupuestos e instalaciones fotovoltaicas.

## Descripción

El proyecto permite centralizar la información de clientes, crear presupuestos solares, registrar instalaciones y acceder a un módulo de ayuda para el usuario.

La aplicación está dividida en dos partes principales:

- `frontend`: interfaz de usuario desarrollada con React y Vite.
- `backend`: API REST desarrollada con Node.js, Express y MongoDB.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- React
- Vite
- Node.js
- Express
- MongoDB
- Mongoose
- npm

## Instalación frontend

Instalar dependencias del frontend:

```bash
cd frontend
npm install
```
## Iniciar el frontend

```bash
cd frontend
npm run dev
```
## Instalación backend

Instalar dependencias del backend:

```bash
cd backend
npm install
```

## Iniciar el backend

```bash
cd backend
npm start
```

## Variables de entorno

El backend utiliza un archivo `.env` para configurar el puerto, la conexión con MongoDB y la clave de autenticación.

## Funcionalidades principales

- Registro e inicio de sesión de usuarios.
- Gestión de clientes.
- Gestión de presupuestos solares.
- Cálculos automáticos de potencia, producción y cobertura.
- Exportación de presupuestos en PDF.
- Gestión de instalaciones.
- Módulo de ayuda.
- Diseño responsive.
